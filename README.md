# Вход монитора

Приложение для строки меню macOS. Рассчитано на Mac с Apple Silicon и HUAWEI MateView GT ZQE‑CAA, подключённый к Mac по USB‑C, а к ПК с Windows по DisplayPort. Требуется macOS 14.4 или новее.

- Левый клик показывает этот Mac. Если USB‑C уже выбран, рядом со значком ненадолго появляется «Уже на Mac».
- Правый клик или Control‑клик открывает список источников, настройку левого клика и выход. Снимите галочку «Левый клик переключает на Mac», чтобы оба клика открывали меню.
- «Зеркалировать при другом входе» объединяет рабочий стол Huawei и активного экрана MacBook, пока Huawei показывает DisplayPort или HDMI. При выборе USB‑C или снятии галочки приложение возвращает исходный режим и расположение дисплеев. Настройка выключена по умолчанию. Ручная смена входа определяется при следующем опросе.
- При потере связи раздел «Последнее подключение» показывает время наблюдения, доступный серийный номер и последнее известное состояние. ID EDID относится к монитору. Его можно скопировать целиком.
- Состояние USB‑C определяется по ответу монитора. Выбранный DisplayPort сам по себе не подтверждает, что Windows подаёт сигнал.

## Сборка

Откройте `MonitorInput.xcodeproj` в Xcode 16 или новее, выберите схему **MonitorInput** и нажмите Run. Сочетание Command‑U запускает тесты.

## Управление монитором

DDC/CI выполняется в отдельной последовательной очереди. Перед каждой сменой входа проверяются модель, контрольная сумма EDID, идентификатор сеанса подключения и действующий вход. Приложение записывает только VCP `0x60` со значением `15` (DisplayPort) или `16` (USB‑C). После запроса оно проверяет выбранный вход и при необходимости повторяет команду один раз. Настройка и последнее наблюдение хранятся локально.

Утилита использует внутренний интерфейс IOAV в macOS. Если он недоступен, меню показывает состояние связи без попытки переключения. Для доступа к DDC приложение собирается без App Sandbox с включённым Hardened Runtime и локальной подписью. Homebrew, сетевое подключение и установка системных компонентов не нужны. [Справка m1ddc о доступе к DDC/CI](https://github.com/waydabber/m1ddc)
