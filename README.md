# Вход монитора

Приложение для строки меню macOS. Требуется Mac с Apple Silicon, macOS 14.4 или новее и подключение, на котором монитор отвечает на команды смены входа DDC/CI (`VCP 0x60`). На HUAWEI MateView GT ZQE‑CAA проверено переключение между USB‑C и DisplayPort.

## Использование

- Правый клик или Control‑клик открывает меню. Если подключено несколько дисплеев, выберите нужный монитор в подменю «Монитор».
- В разделе «Настроить входы → Вход Mac» выберите порт, к которому подключён Mac. Галочка показывает сохранённый выбор. Там же можно назвать входы, например «Linux» или «Консоль».
- В разделе «Настроить входы → Показывать входы» можно убрать неиспользуемые порты из основного списка и вернуть их. Названия, видимость и вход Mac сохраняются отдельно для каждого монитора. Быстрое переключение использует назначенный вход Mac независимо от его видимости.
- Галочка рядом со входом отмечает источник, который выбрал монитор. Состояние видеосигнала на портах остаётся неизвестным.
- Левый клик переключает выбранный монитор на настроенный вход Mac. Если он уже выбран, рядом со значком появляется «Уже на Mac». Галочка «Левый клик переключает на Mac» меняет действие левого клика.
- «Зеркалировать при другом входе» объединяет рабочий стол выбранного монитора и активного экрана MacBook, пока выбран другой источник. При возврате на сохранённый вход Mac или снятии галочки приложение восстанавливает исходную раскладку. Для зеркалирования требуется однозначное совпадение дисплея в Core Graphics по модели и серийному номеру EDID.
- При отключении раздел «Последнее подключение» показывает время наблюдения и данные выбранного монитора.

## Профили мониторов

Утилита читает модель из EDID, выбранный вход из VCP `0x60` и доступные коды из ответа `Capabilities`. Мониторы иногда сообщают неполный список. Переключение входа джойстиком помогает обнаружить код из фактического ответа. Если монитор отказывается отвечать по кабелю Mac после смены входа, для возврата потребуется его собственное меню.

[Resources/MonitorProfiles.json](Resources/MonitorProfiles.json) сопоставляет производителя и модель EDID с названиями портов. Коды производителя и модели записаны в шестнадцатеричном формате из четырёх символов, коды портов — из двух. Добавляйте новый профиль по проверенным кодам и указывайте, на каком подключении чтение и переключение подтверждены. Личные названия остаются в настройках macOS.

## Сборка

Откройте `MonitorInput.xcodeproj` в Xcode 16 или новее, выберите схему **MonitorInput** и нажмите Run. Сочетание Command‑U запускает тесты.

Приложение использует внутренний интерфейс IOAV в macOS. Оно отправляет команды выбора входа по одному, проверяет EDID перед записью и читает результат после команды. Для доступа к DDC проект собирается без App Sandbox с включённым Hardened Runtime и локальной подписью. [Справка m1ddc о доступе к DDC/CI](https://github.com/waydabber/m1ddc)
